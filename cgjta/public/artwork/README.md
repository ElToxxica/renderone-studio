# Artwork

Drop final artwork into this folder using these names. Any of `.png`, `.jpg`,
`.webp` or `.svg` works; if several exist, PNG wins, then JPG, WebP, SVG.
No code changes or restart needed.

| File                | Used for                                   | Size                        |
|---------------------|--------------------------------------------|-----------------------------|
| `logo.*`            | Sidebar, sign-in pages, receipts, cards    | Square, at least 256×256 px |
| `card-exco.*`       | Background of the EXCO membership card     | 1012×638 px (ID-1 @ 300 dpi) |
| `card-premier.*`    | Background of the Premier membership card  | 1012×638 px                 |
| `card-member.*`     | Background of the Member card              | 1012×638 px                 |
| `card-back.*`       | Optional: back of every card (falls back to the tier artwork) | 1012×638 px |

Name, membership number, tier, photo and validity are drawn on top of the
card artwork, so keep the lower-left area fairly plain.

The current files are placeholders.
